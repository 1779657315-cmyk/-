## 1.c语言基础
【问】：**static关键字在c语言中有哪些作用？**
【答】：
	static关键字有三个主要作用：
	1. **修饰局部变量**：改变变量的生命周期，使其在程序整个运行周期都在。但作用域仍限于函数内部。变量只初始化一次，保留上次调用的值
	2. **修饰全局变量**：限制变量的作用域，使其只能在当前源文件中调用，其他文件无法extern引用
	3. **修饰函数**：限制函数的作用域，使其只能在当前源文件中调用，实现函数的内部链接

---

【问】：**const和#define的区别是什么？**
【答】：
		主要区别如下：
		1. **处理阶段**：define是预处理阶段进行文本替换；const是编译阶段处理
		2. **类型检查**：define没有类型检查；const有类型检查，更安全
		3. **调试**：define的宏不可以调试；const的可以调试
		4. **内存分配**：define不分配内存（多次使用多次拷贝）；const分配内存
		5. **作用域**：define无作用域限制；const有
		6. **指针**：define不能定义指针；const可以

---
【问】：**sizeof 和 strlen 有什么区别？**
【答】：
		主要区别如下：
		1. **性质**：sizeof是运算符，在编译时计算；strlen是库函数，在运算时计算
		2. **计算内容**：sizeof计算变量或类型占内存的字节数；strlen计算字符串实际长度（不包括\0）
		3. **参数类型**：sizeof可用于任何类型；strlen只能用于字符串
		4. **返回值**：sizeof返回类型size_t；strlen返回字符串长度，也是size_t
		所以sizeof只返回4，8，16，32这些
		 strlen就可以用来遍历数组或者指针获取字符串长度（不会计入\0，所以一般用+1） 

---
【问】：**++i和i++有什么区别？**
【答】：
		主要区别如下：
		1. **执行顺序**：
			1. ++i 先自增，再返回
			2. i++先返回，再自增
		2. **效率**：
			1. ++i的执行效率很高

---
【问】：**break和continue的区别**
【答】：
		主要区别如下：
		1. break是终止循环
		2. continue是跳过本次循环，进入下次循环判断

## 2.指针相关
【问】：**什么是野指针？什么是空指针？如何避免野指针？**
【答】：
		**野指针**是指向未知或无效地址的指针，使用野指针会导致程序崩溃或产生不可预测行为
		**避免途径：**
		1. 初始化
		2. 释放后置空：
		3. 注意边界运算
```c
		free(p);
		p = NULL;
```
	    **空指针**即指向NULL的指针
	    悬空指针：指向被释放地址或无效数据的指针
---

## 3.数组与字符串
【问】：字符串在c语言中的本质是什么？为什么字符串需要以\0结尾？
【答】：
		字符串本质是一个字符数组，以空字符\0结尾。
```c
		//strlen实现原理
		size_t strlen(const char *str)
		{
			int len = 0;
			while(*str != \0)
			{
				len++;
				str++;
			}
			return len;
		}
```

---

【问】：`char str[] = "hello"` 和 `char *str = "hello"` 有什么区别？
【答】：
		主要区别：
		1. `char str[] = "hello"`是定义了一个字符串数组，内容是”hello“。内容可修改，数组不能整体重新赋值。
		2. `char *str = "hello"`是定义了一个指针，指向字符串常量。字符串内容不能修改，但指针可以改变指向。

---

【问】：如何实现字符串复制？
【答】：
```c
		char *str_copy(const char *tar_str)
		{
			char *str = malloc(strlen(tar_str)+1);
			char *start = str;
			while(*tar_str != '\0')
			{
				*str = *tar_str;
				str++;
				tar_str++;
			}
			*str = *tar_str;
			return start;
		}
```

char *str_rollback(const char *tar_str)
{
    char *str = malloc(strlen(tar_str) + 1);
    int tar_str_len = strlen(tar_str);
    int str_len = 0;
    while (tar_str_len != 0)
    {
        str[str_len] = tar_str[tar_str_len - 1];

        str_len++;
        tar_str_len--;
    }
    str[str_len] = '\0';

【问】：**malloc和calloc的区别**
【答】：
		主要区别如下：
		1. 初始化：malloc不初始化内存，calloc将所有字节初始化为0
		2. 性能：malloc速度稍快，calloc速度稍慢
		3. 安全性：calloc会检查内存是否溢出

---

【问】：**什么是内存泄漏？**
【答】：
		动态分配内存没有及时得到释放，导致无法再次使用，造成资源浪费。

## 5.函数与结构体
【问】：**union和ifdef的区别**
【答】：
```c
		/*结构体（struct）：
		*所有成员各自占用独立的内存空间，总大小约等于所有成员大小之和，同时还需要考虑内存对齐
		*/
		struct Student
		{
		    int id;          // 4字节
		    char name[20];   // 20字节
		    float score;     // 4字节
		};

		// 总大小：至少28字节
		// 实际大小需要考虑内存对齐，对齐单位4字节
```
```c
		/*联合体（union）：
		*所有成员共享同一块内存空间，总大小由最大成员决定，同时还需要考虑内存对齐。
		*/
		union Data
		{
		    int i;          // 4字节
		    float f;        // 4字节
		    char str[20];   // 20字节
		};

		// 总大小：20字节
		// 实际大小需要考虑内存对齐
```
其中结构体内存对齐原则：
1. 结构体整体对齐值通常取成员中最大的对齐值；
2. 结构体最终大小必须是整体对齐值的整数倍；
